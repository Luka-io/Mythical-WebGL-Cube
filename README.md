# Mythical-WebGL-Cube

It uses WebGL to render a 3D Cube , this project was made for fun in https://shrink.hackclub.com/ !

## how to use it

Copy the uri.txt content and paste it inside your browser.

## how it works

It uses WebGL to render a 3D Cube , takes mouse pointer as inputs to move the Cube and makes sounds...

## building

If you want to build from source or make one yourself, start by changing or taking the index.html in src and run the Commands :
```
npm install
node build.mjs
```

GOOD LUCK getting your code under 3KB !!!
